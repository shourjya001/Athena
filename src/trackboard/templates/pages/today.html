How it works

Ingest

A scout agent polls public ATS APIs nightly, de-duplicates by company + title + location, and closes a role after it vanishes from three consecutive runs.

Score

A BM25 shortlist, then a recruiter-style pass across four pillars: direct skills, transferable depth, adjacent tooling, and quantified impact. If the model is offline you see "Unscored", not a made-up number.

Prepare

Tailored résumés are selected from your own bullet bank and rejected if a contact field goes missing. Practice is a spaced-repetition queue across 26 patterns.

About the build

Athena is a Python, FastAPI, Jinja and HTMX app on a single SQLite file, with no client-side framework and no ORM. Eight small agents read and write the same tables instead of calling each other, which is why it runs on a free serverless plan. The status page shows every agent's last run. Built by Shourjya Hazra.
