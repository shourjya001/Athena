# Resume Tailoring & Experience Discovery Skill

This skill guides Trackboard's tailoring engine to surface undocumented experiences, align terminology with the target Job Description, and evaluate confidence across 4 transparent pillars without ever fabricating false claims.

---

## 1. The 4-Pillar Transparent Confidence Matrix

Trackboard evaluates candidate-to-JD alignment using a weighted 4-pillar model:

$$\text{Overall Confidence} = (40\% \times \text{Direct}) + (30\% \times \text{Transferable}) + (20\% \times \text{Adjacent}) + (10\% \times \text{Impact})$$

1. **Direct Match (40%)**:
   - Exact technology overlap (e.g. Python, FastAPI, PostgreSQL, Kubernetes).
   - Domain alignment (Fintech, Core Banking, Developer Tooling).
2. **Transferable Skills (30%)**:
   - Equivalent architecture, scaling, reliability, and leadership capabilities across stacks.
3. **Adjacent Experience (20%)**:
   - Complementary ecosystem tooling (e.g. Kafka & RabbitMQ, Docker & K8s, Redis & Memcached).
4. **Impact & Metric Alignment (10%)**:
   - Quantified outcomes: throughput (TPS), latency reduction, cost savings, uptime, and team velocity.

## 2. Branching Experience Discovery (Gap Interview)

When a critical JD requirement is underrepresented in the candidate's resume, conduct a targeted branching inquiry:

### Branch A: Direct Hands-On Work
* *Probe*: "What specific system did you build or operate with this technology? What was the scale (QPS/throughput/data size)?"
* *Formula*: `[Action Verb]` + `[What Was Built]` + `[Tech Stack]` + `[Measurable Impact]`.

### Branch B: Transferable / Equivalent Stack
* *Probe*: "Did you solve the same architectural challenge using an equivalent tool or pattern? (e.g. RabbitMQ instead of Kafka)?"
* *Framing*: Highlight the architectural paradigm (event-driven messaging, distributed consensus) with transferable proof.

### Branch C: Adjacent / Supporting Role
* *Probe*: "Did you collaborate with or consume APIs from this service? Did you debug or integrate with it?"
* *Framing*: Position as cross-functional systems competency and upstream/downstream ownership.

### Branch D: Personal Projects / Deep Learning
* *Probe*: "Have you built or deployed production prototypes, open-source projects, or modern labs using this stack?"
* *Framing*: Highlight hands-on implementation, modern patterns, and rapid adaptation velocity.

## 3. High-Leverage Gap Analysis
* Across a candidate's top target applications, aggregate shared missing keywords.
* Flag skills that appear across 3+ job descriptions as **High-Leverage Gaps**.
* Provide actionable bridging recommendations that immediately elevate match scores across multiple employers simultaneously.
